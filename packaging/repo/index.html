OpenTelemetry System Packages

Current version: @VERSION@

Linux packages for automatic instrumentation of Java, Node.js, .NET, and Python applications using OpenTelemetry.

This repository is an experiment, and it keeps only the latest version.

Hosting on GitHub Pages exists to exercise the package system and its metadata. Publishing a release replaces the packages that came before it, so superseded versions stop being resolvable through apt or dnf. See Version Retention before you pin a version.

Quick Install (Debian/Ubuntu)

# Add the repository
echo "deb [trusted=yes] @REPO_URL@/debian stable main" | sudo tee /etc/apt/sources.list.d/opentelemetry.list

# Update and install
sudo apt update
sudo apt install opentelemetry

Quick Install (RHEL/Fedora/Amazon Linux)

# Add the repository
cat <<EOF | sudo tee /etc/yum.repos.d/opentelemetry.repo
[opentelemetry]
name=OpenTelemetry Auto-Instrumentation System Packages
baseurl=@REPO_URL@/rpm/packages
enabled=1
gpgcheck=0
EOF

# Install
sudo dnf install opentelemetry

Available Packages

  • opentelemetry - Metapackage that installs all components
  • opentelemetry-injector - LD_PRELOAD-based auto-instrumentation injector
  • opentelemetry-java-autoinstrumentation - Java agent for automatic instrumentation
  • opentelemetry-nodejs-autoinstrumentation - Node.js agent for automatic instrumentation
  • opentelemetry-dotnet-autoinstrumentation - .NET agent for automatic instrumentation
  • opentelemetry-python-autoinstrumentation - Python agent for automatic instrumentation

Individual Package Installation

You can install individual packages if you only need specific language support:

# Install only Java instrumentation
sudo apt install opentelemetry-injector opentelemetry-java-autoinstrumentation

# Install only Node.js instrumentation
sudo apt install opentelemetry-injector opentelemetry-nodejs-autoinstrumentation

# Install only .NET instrumentation
sudo apt install opentelemetry-injector opentelemetry-dotnet-autoinstrumentation

# Install only Python instrumentation
sudo apt install opentelemetry-injector opentelemetry-python-autoinstrumentation

Version Retention

This repository carries only the latest version of each package, currently @VERSION@. Each release replaces the packages that preceded it, so a superseded version is no longer available from the APT or YUM repository. Pinning a package to an exact version holds only for as long as that version is the latest one: an install that pins an older version starts failing as soon as the next release is published.

This is a deliberate property of the interim GitHub Pages hosting, which exists to exercise the package system and its metadata rather than to serve as a package archive. The policy will change when the packages move to dedicated repository infrastructure; issue #65 tracks that discussion.

Every version stays available outside this repository. Each release attaches its .deb and .rpm files as assets on the releases page, so you can download a specific version and install it directly:

On Debian and Ubuntu:

sudo dpkg -i opentelemetry-injector_<version>_amd64.deb

On RHEL, Fedora, and Amazon Linux:

sudo rpm -ivh opentelemetry-injector-<version>-1.x86_64.rpm

A package installed that way is still upgraded on the next apt upgrade or dnf upgrade. Hold it explicitly with apt-mark hold or dnf versionlock if the version has to stay put.
